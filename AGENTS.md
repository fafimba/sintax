# Instrucciones para agentes

## Guardado del trabajo (commits y pushes)

Este proyecto se desarrolla habitualmente desde sesiones remotas (Claude Code
web/móvil), donde el entorno es efímero: todo lo que no se sube a GitHub se
pierde al terminar la sesión.

- Haz commits frecuentes a medida que avanzas, con mensajes claros y
  descriptivos. No acumules todo el trabajo en un único commit final.
- Haz push de la rama de trabajo después de cada bloque de trabajo
  significativo, y siempre antes de terminar la sesión.
- Nunca des una tarea por terminada sin haber hecho commit y push de todos
  los cambios.
- Al final de cada sesión, indica en la respuesta en qué rama ha quedado el
  trabajo, para poder continuar desde ahí en la siguiente sesión.
